# SGR Completion

## Key

- `missing` - Not implemented yet
- `done` - Implemented
- `partial` - Partially implemented
- `not planned` - Will not be implemented

| SGR Code | Description                                                 | Note                                                                                                                                                                                                                                    | Completion  |
| -------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| 0        | Reset or normal                                             | All attributes become turned off                                                                                                                                                                                                        | done        |
| 1        | Bold or increased intensity                                 | As with faint, the color change is a PC (SCO / CGA) invention.                                                                                                                                                                          | done        |
| 2        | Faint, decreased intensity, or dim                          | May be implemented as a light font weight like bold.                                                                                                                                                                                    | done        |
| 3        | Italic                                                      | Not widely supported. Sometimes treated as inverse or blink.                                                                                                                                                                            | done        |
| 4        | Underline                                                   | `4:N` selects a style as in kitty: 0 none, 1 single, 2 double, 3 curly, 4 dotted, 5 dashed; N above 5 is dashed; an empty `4:` is a single underline. Plain `4` is single. Extensions exist for Kitty, VTE, mintty, iTerm2 and Konsole. | done        |
| 5        | Slow blink                                                  | Sets blinking to less than 150 times per minute (~1 Hz; 500 ms on/off)                                                                                                                                                                  | done        |
| 6        | Rapid blink                                                 | MS-DOS ANSI.SYS, 150+ per minute; Freminal implements at ~3 Hz (167 ms on/off)                                                                                                                                                          | done        |
| 7        | Reverse video or invert                                     | Swap foreground and background colors; inconsistent emulation                                                                                                                                                                           | done        |
| 8        | Conceal or hide                                             | Not widely supported.                                                                                                                                                                                                                   | not planned |
| 9        | Crossed-out, or strike                                      | Characters legible but marked as if for deletion. Not supported in Terminal.app.                                                                                                                                                        | done        |
| 10       | Primary (default) font                                      |                                                                                                                                                                                                                                         | not planned |
| 11–19    | Alternative font                                            | Select alternative font n − 10                                                                                                                                                                                                          | not planned |
| 20       | Fraktur (Gothic)                                            | Rarely supported                                                                                                                                                                                                                        | not planned |
| 21       | Doubly underlined; or: not bold                             | Double underline per ECMA-48 8.3.117, as in kitty, xterm, Ghostty and WezTerm (the same as `4:2`; SGR 24 clears it). Freminal does not treat 21 as bold-off; use 22 or 221 for that.                                                    | done        |
| 22       | Normal intensity                                            | Neither bold nor faint; clears both. For independent control see 221 and 222.                                                                                                                                                           | done        |
| 23       | Neither italic, nor blackletter                             |                                                                                                                                                                                                                                         | done        |
| 24       | Not underlined                                              | Neither singly nor doubly underlined; clears every underline style (single, double, curly, dotted, dashed)                                                                                                                              | done        |
| 25       | Not blinking                                                | Turn blinking off                                                                                                                                                                                                                       | done        |
| 26       | Proportional spacing                                        | ITU T.61 and T.416, not known to be used on terminals                                                                                                                                                                                   | not planned |
| 27       | Not reversed                                                |                                                                                                                                                                                                                                         | done        |
| 28       | Reveal                                                      | Not concealed                                                                                                                                                                                                                           | not planned |
| 29       | Not crossed out                                             |                                                                                                                                                                                                                                         | done        |
| 30–37    | Set foreground color                                        |                                                                                                                                                                                                                                         | done        |
| 38       | Set foreground color                                        | Next arguments are 5;n or 2;r;g;b                                                                                                                                                                                                       | done        |
| 39       | Default foreground color                                    | Implementation defined (according to standard)                                                                                                                                                                                          | done        |
| 40–47    | Set background color                                        |                                                                                                                                                                                                                                         | done        |
| 48       | Set background color                                        | Next arguments are 5;n or 2;r;g;b                                                                                                                                                                                                       | done        |
| 49       | Default background color                                    | Implementation defined (according to standard)                                                                                                                                                                                          | done        |
| 50       | Disable proportional spacing                                | T.61 and T.416                                                                                                                                                                                                                          | not planned |
| 51       | Framed                                                      | Implemented as "emoji variation selector" in mintty.                                                                                                                                                                                    | missing     |
| 52       | Encircled                                                   |                                                                                                                                                                                                                                         | missing     |
| 53       | Overlined                                                   | Not supported in Terminal.app                                                                                                                                                                                                           | missing     |
| 54       | Neither framed nor encircled                                |                                                                                                                                                                                                                                         | missing     |
| 55       | Not overlined                                               |                                                                                                                                                                                                                                         | missing     |
| 58       | Set underline color                                         | Not in standard; implemented in Kitty, VTE, mintty, and iTerm2. Next arguments are 5;n or 2;r;g;b (also the colon forms). Not swapped by reverse video.                                                                                 | done        |
| 59       | Default underline color                                     | Not in standard; implemented in Kitty, VTE, mintty, and iTerm2. The underline then follows the effective foreground colour.                                                                                                             | done        |
| 60       | Ideogram underline or right side line                       | Rarely supported                                                                                                                                                                                                                        | not planned |
| 61       | Ideogram double underline, or double line on the right side |                                                                                                                                                                                                                                         | not planned |
| 62       | Ideogram overline or left side line                         |                                                                                                                                                                                                                                         | not planned |
| 63       | Ideogram double overline, or double line on the left side   |                                                                                                                                                                                                                                         | not planned |
| 64       | Ideogram stress marking                                     |                                                                                                                                                                                                                                         | not planned |
| 65       | No ideogram attributes                                      | Reset the effects of all of 60–64                                                                                                                                                                                                       | not planned |
| 73       | Superscript                                                 | Implemented only in mintty                                                                                                                                                                                                              | not planned |
| 74       | Subscript                                                   |                                                                                                                                                                                                                                         | not planned |
| 75       | Neither superscript nor subscript                           |                                                                                                                                                                                                                                         | not planned |
| 90–97    | Set bright foreground color                                 | Not in standard; originally implemented by aixterm                                                                                                                                                                                      | done        |
| 100–107  | Set bright background color                                 |                                                                                                                                                                                                                                         | done        |
| 221      | Bold off (independent)                                      | Kitty extension: clears bold only and leaves faint alone. Not in ECMA-48.                                                                                                                                                               | done        |
| 222      | Faint off (independent)                                     | Kitty extension: clears faint only and leaves bold alone.                                                                                                                                                                               | done        |
